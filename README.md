# Free-Courses-Roadmap-for-KTU-

Link : https://polygon-arch.github.io/Free-Courses-Roadmap-for-KTU-/

A responsive, Firebase-powered web application to track a 12-week AI and IoT learning roadmap and manage KTU activity points.

An interactive roadmap application built with HTML, CSS, JavaScript, and Firebase. It features secure user authentication and real-time progress syncing via Cloud Firestore to track coursework across Google, NPTEL, IBM, Microsoft, and AWS. Designed with a mobile-first accordion UI to help students systematically complete certifications, manage activity points, and monitor their global progress through dynamically updating visual dashboards.
